Зашифровать файл алгоритмом aes-256-cbc (ключ должен быть 256 бит, размер блока 128 бит).

1. Сгенерируем 256-битовый ключ.
[foo@foo ~/c/openssl]$ openssl rand -hex 32
cb3a421be5782f518f225ea93f1d193958cbaaabad6d7eaa80e4d5815b296374

2. Сгенеритуем IV
[foo@foo ~/c/openssl]$ openssl rand -hex 16
9500d511fc2332115997b00e1c8d47f0

3. Зашифруем файл openssl-encrypt.txt
[foo@foo ~/c/openssl]$ openssl enc \
	-aes-256-cbc \
	-K cb3a421be5782f518f225ea93f1d193958cbaaabad6d7eaa80e4d5815b296374 \
	-iv 9500d511fc2332115997b00e1c8d47f0 \
	-e \
	-in openssl-encrypt.txt \
	-out openssl-encrypt.txt.encrypted
[!] -e - encode, -d - decode

4. Расшифруем файл:
[foo@foo ~/c/openssl]$ openssl enc \
	-aes-256-cbc \
	-K cb3a421be5782f518f225ea93f1d193958cbaaabad6d7eaa80e4d5815b296374 \
	-iv 9500d511fc2332115997b00e1c8d47f0 \
	-d \
	-in openssl-encrypt.txt.encrypted \
	-out openssl-encrypt.txt.decrypted

[foo@foo ~/c/openssl]$ sha256sum *
789bc6b017272d71fbbd7f45a232e49a8ff1c7028943dc5c4e75453370a07da3  openssl-encrypt.txt
789bc6b017272d71fbbd7f45a232e49a8ff1c7028943dc5c4e75453370a07da3  openssl-encrypt.txt.decrypted
a62fc307dadb3af776ed861130811c1b7004f5457e6dc886c0391f73f1175723  openssl-encrypt.txt.encrypted

[foo@foo ~/c/openssl]$ openssl dgst *

Вычисление хэш-значения.
1. Смотрим какие алгоритмы поддерживаются:

$ openssl dgst -list
Supported digests:
-blake2b512                -blake2s256                -md4
-md5                       -md5-sha1                  -ripemd
-ripemd160                 -rmd160                    -sha1
-sha224                    -sha256                    -sha3-224
-sha3-256                  -sha3-384                  -sha3-512
-sha384                    -sha512                    -sha512-224
-sha512-256                -shake128                  -shake256
-ssl3-md5                  -ssl3-sha1                 -whirlpool

2. Вычислим хэш-значение sha3-256:

$ openssl dgst -sha3-256 /etc/defaults/rc.conf
