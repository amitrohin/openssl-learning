Зашифровать файл алгоритмом aes-256-cbc (ключ должен быть 256 бит, размер блока 128 бит).

1. Сгенерируем 256-битовый ключ.
[foo@foo ~/c/openssl]$ openssl rand -hex 32
cb3a421be5782f518f225ea93f1d193958cbaaabad6d7eaa80e4d5815b296374

2. Сгенеритуем IV
[foo@foo ~/c/openssl]$ openssl rand -hex 16
9500d511fc2332115997b00e1c8d47f0

3. Зашифруем файл openssl-encrypt.txt
[foo@foo ~/c/openssl]$ openssl enc \
	-aes-256-cbc \
	-K cb3a421be5782f518f225ea93f1d193958cbaaabad6d7eaa80e4d5815b296374 \
	-iv 9500d511fc2332115997b00e1c8d47f0 \
	-e \
	-in openssl-encrypt.txt \
	-out openssl-encrypt.txt.encrypted
[!] -e - encode, -d - decode

4. Расшифруем файл:
[foo@foo ~/c/openssl]$ openssl enc \
	-aes-256-cbc \
	-K cb3a421be5782f518f225ea93f1d193958cbaaabad6d7eaa80e4d5815b296374 \
	-iv 9500d511fc2332115997b00e1c8d47f0 \
	-d \
	-in openssl-encrypt.txt.encrypted \
	-out openssl-encrypt.txt.decrypted

[foo@foo ~/c/openssl]$ sha256sum *
